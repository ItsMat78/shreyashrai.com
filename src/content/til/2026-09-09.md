### [Leetcode 4038 - Count Integers Appearing in a Single Block](https://leetcode.com/problems/count-integers-appearing-in-a-single-block)
My first approach was to basically save all frequencies of each number. Then try to find the starting and ending indexes of any contiguous block, and if the gap between starting and ending of that block isn't same as the frequencies of said digit inside the block, it's invalid. If not, it's valid.
I wrote:

```cpp
class Solution {
public:
    int countSpecialIntegers(vector<int>& nums) {
        int n = nums.size();
        unordered_map<int, int> freq;
        int count = 0;
        if (n==1) return 1;
        for (int x : nums){
            freq[x]++;
        }
        int start = -1;
        int end = -1;
        for (int i = 0; i < n; i++){
            if (i>0 && i<n-1){
                if (nums[i-1] != nums[i] && nums[i+1] == nums[i]){
                    start = i;
                    end = i;
                }
                if (nums[i-1] == nums[i] && nums[i+1] != nums[i]){
                    end = i;
                }
                if (nums[i-1] != nums[i] && nums[i+1] != nums[i]){
                    start = i;
                    end = i;
                }
            }
            if (i==0){
                if (nums[i+1] == nums[i]) start = i;
                else {
                    start = i;
                    end = i;
                }
            }
            if (i == n-1){
                if (nums[i-1] == nums[i]) end = i;
                else {
                    start = i;
                    end = i;
                }
            }
            if (end >= start && freq[nums[i]] == (end - start + 1)) count++;
        }
        return count;
    }
};
```

which I am 100% sure I overcomplicated.
I'm also sure the small constraints on this would make it easier, but overall, this is the best I could do for now.

But I do think I can make an array of size 100 and store true false values there as another approach?

Yes! I can store the count of starts of each continuous block and if some number has more than one start then it won't be counted. Count all the ones hehe.

```cpp
class Solution {
public:
    int countSpecialIntegers(vector<int>& nums) {
        int n = nums.size();
        vector<int> runs(101, 0);
        for (int i=0; i < n; i++){
            if (i == 0 || nums[i] != nums[i-1]) runs[nums[i]]++;
        }
        int count = 0;
        for (int x : runs){
            if (x == 1) count++;
        }
        return count;
    }
};
```

### [Leetcode 3870 - Count Commas in Range](https://leetcode.com/problems/count-commas-in-range?envType=daily-question&envId=2026-09-08)
Simplest code ever. Saved by the constraint of max `n` being `10^5`. 
```cpp
class Solution {
public:
    int countCommas(int n) {
        if (n < 1000) return 0;
        else return (n - 999);
    }
};
```

### [Leetcode 3871 - Count Commas in Range II](https://leetcode.com/problems/count-commas-in-range-ii?envType=daily-question&envId=2026-09-09)
Not so simple man. So many numbers. But we made it. I counted each comma in each possible range and added them.
```cpp
class Solution {
public:
    long long countCommas(long long n) {
        long long sum = 0;
        if (n < 1000) return 0;
        if (n >= 1e3 && n < 1e6) sum = 1*(n-(1e3-1));
        if (n >= 1e6 && n < 1e9) sum = 1*(1e6-1e3)+2*(n-(1e6-1));
        if (n >= 1e9 && n < 1e12) sum = 1*(1e6-1e3)+2*(1e9-1e6)+3*(n-(1e9-1));
        if (n >= 1e12 && n < 1e15) sum = 1*(1e6-1e3)+2*(1e9-1e6)+3*(1e12-1e9)+4*(n-(1e12-1));
        if (n == 1e15) sum = 1*(1e6-1e3)+2*(1e9-1e6)+3*(1e12-1e9)+4*(1e15-1e12)+5*(n-(1e15-1)); 
        return sum;
    }
};
```
